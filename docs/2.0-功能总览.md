# 邗上课表 2.0 功能总览

> 依据发给内测账号「测试用户」的收件箱全部 24 条测试版记录整理（2026-09-15 → 2026-09-22，test → test61）。
> 本文按功能主题归类，版本流水见文末附录。

---

## 一、AI 日程（2.0 的核心新增）

把"随口一句话"变成课表上的日程：

- **三种输入**：文字、语音、拍照/图片（活动海报、班级通知、聊天截图都能认）。
- **语音录入**（多轮打磨定型）：
  - 长按底部按钮弹语音层，免手持录音，点「完成录音」识别——彻底修掉了早期"松手不发送、上滑不取消"的手势问题；
  - **边说边出字**：服务端 MiMo ASR 分段转写实时上屏（约 2.5 秒一批），波形随真实音量起伏，快攻慢放更跟手；不挑手机（不依赖系统语音服务）；
  - **地名更准**：识别时自动带上"你课表里出现过的楼名 + 扬大常见楼宇"词表，显著减少"文津楼↔文经楼"这类同音错认；
- **添加页按钮变身**：进入「添加」页后，底部中间按钮自动从「添加」丝滑变身为「语音」（图标翻转+文字渐变），点它直接开始说话；离开页面自动变回。
- **确认弹层**：单条日程先给"确认日程"卡片（原话、事项/日期/时间/地点可改），多操作走完整预览页；AI 会额外提炼一个**简写标题**放在课表格子上（如「团建」），完整标题在详情里。
- 日程与课程**同显在周/日视图**，支持本地提醒（与课程提醒同排）；DDL/全天类日程不占网格，以当日顶部横条展示。
- **边界**：AI 单次调课/取消课程暂未开放（避免误改整学期）。

## 二、课表阅读体验重构

- **信息层级**：课名（最大、半粗）＞ 教室号（独立醒目行）＞ 楼名（次要行）＞ 教师（默认收起，可在我的页开启）＞ 周次/完整课名（只在详情）。
- 字号**固定紧凑字阶**（加粗排密），宽度不够时自动缩字，**绝不省略号截断**——教室号、时间、地点永远完整可读。
- **课程简称**：编辑课程可设简称（如「大物」），卡片优先显示，两端同步、分享口令也带。
- **冲突合并块**：同一时段多个课程/日程不再并排细条（哪条都看不清），合并为「N 个活动」块——每个活动一个**彩色小方块**（用回自己的颜色、占满格子、字号随数量自适应）；点按展开列表与课表同规则排布：**按时间先后排序、同一时段的并排显示**，每项带节次/时间说明和原始卡片。
- 跨作息切换周（换季）时间栏不再溢出。

## 三、调休课表（2.0 后期新增）

- 「我的 → 调休课表」：**放假**（当天不上课，表头显示"放假"）与**补课**（如周六补周三的课，按指定星期显示课表）。
- 两种录入：**手动设置**（日期 + 放假/补课 + 星期 + 备注）；**上传调休通知**（截图或粘贴文字，AI 自动提取"哪天放假、哪天补周几的课"，勾选确认后保存）。
- 识别过程有进度动画 + 预计剩余秒数；失败给出具体原因（超时/服务不可用/图片过大）；截图自动压缩到 1600px。
- 调休安排**多设备云同步**（App 与网页版共用一份数据，删除也同步）。
- 实测：扬大中秋国庆通知（13 天假期 + 9/20 补周二、10/10 补周三）文字和截图两种形态全部正确解析。

## 四、导入体系

- **截图 / 表格 AI 识别**：上传课表截图或 Excel/CSV，服务端 AI 识别课程、星期、节次、周次、地点，先预览核对再保存；上传前提示脱敏、文件即转即删。
- **扬大教务**：App 内 WebView 登录抓取。
- **其他学校教务**：学校选择页（搜索 + A-Z 索引 + 教务系统类型标注），学校名单可远程扩充不用发版；名单外学校可走**通用教务导入**（输入教务网址）。
- **分享口令**：6 位口令导入同学课表，可选覆盖同名学期。
- 添加页与 App 其余界面风格统一；识别结果的学期设置挪到预览页（先识别再确认学期）。

## 五、共同空闲

- 表述从"第几节课有空"改为「**有空 08:00-09:40、14:30-16:10**」这种时间段；状态词统一为「我有空/我没空/对方没空/都没空」。
- 小屏上时间段不再截断（自动折行）；网页版模块同步（并读取你在网页版设置的同一份自定义作息）。

## 六、账户与安全

- **修改用户名 + 头像**（App 与网页版都可）：点头像换图、改名（2-32 位中英文/数字/_/-），服务端做唯一性与魔数校验、限流、旧头像即时清理。
- **切换账号数据隔离**：同一设备换账号自动隔离旧账号本地数据（含删除墓碑），不会再串号或误删云端数据。
- **登录保持**：refresh token 有效期延长到 **365 天**（原 90 天对不过寒暑假，返校学生不再被强制退出）；网页版在 iOS 清除 Cookie 后可用本地备份凭据无感自救；会话真失效时约 2 秒进登录页（不再长时间卡"恢复中"）。

## 七、服务端与稳定性（用户可感知的部分）

- AI 解析（MiMo）：日程理解、课表文件识别、调休通知解析、ASR 语音转写；全部即转即弃、不落库。
- API 地址从 IP 正式切换到域名 `api.seanyan.store`。
- 推送、通知收件箱、版本发布管理（管理后台可视化：发布/定向名单/通知）。

## 八、网页版（PWA）同步

2.0 期间网页版与 App 对齐上线：全新玻璃质感 UI + 深色模式、个人日程与调休渲染、卡片信息层级与冲突合并、修改用户名/头像、调休 AI 录入（截图/文字）、共同空闲时间段表述。
**边界**：网页版无语音录入（提示到 App 使用）；日程提醒由 App 发送。

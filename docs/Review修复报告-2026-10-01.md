## 修复清单

### 数据保护（报告修复顺序第 1 批）

- **R01 账号串号**：settings 表新增 `session_epoch` 会话代次。切号清库时写入新代次（auth_repository）；同步在启动、每批 push 发送前、pull 事务前后核对代次，不一致即放弃本轮（sync_repository），迟到响应不再写进新账号的库。
- **R02 切号漏清调休表**：`_wipeLocalDataForAccountSwitch` 补删 `scheduleOverrides`。
- **R03 墓碑整表清空**：push 开始时快照墓碑 ID，全部批次成功后只删快照内的行；push 期间新增的删除留给下一轮。
- **R04 旧墓碑删新修改**：五个 `_apply*` 的 deleted 分支全部改为版本比较（`remoteUpdated.isAfter(local.updatedAt)` 才删）。
- **R05 秒精度**：全库 DateTime 列挂 `DateTimeMsConverter`（毫秒整数存储，SQL 类型不变）；v7 迁移把存量秒值 ×1000（<1e11 守卫，幂等安全）；schemaVersion 6→7。
- **R06 批次漏 overrides**：批次总数改为五类列表取 max；applied 计数补 overrides。
- **R11 v1 迁移断裂**：迁移重写为"全部 DDL → 原生 SQL 回填 uuid/时间"两段式；updated_at 加列改恒定默认值 0 + Dart 回填；uuid 回填全部走 `customSelect/customStatement`，不再踩 typed 查询的列存在性前提。

### 数据入口

- **R12 节次 13-30**：LLM 映射的节次夹进 `[1, SectionTimeConfig.maxSection(=12)]`（新增常量），下游不再 RangeError。
- **R13 脱敏遗漏**：`stripIdentityInfo` 新增两道前置清洗——`<script>/<style>` 整块移除、`<input>/<textarea>/<select>/<button>` 表单控件整体移除（value 属性回显的密码/token/凭据随之消失）。
- **R14 TLS 主机名**：SchoolTlsPlugin 改用平台 `X509TrustManagerExtensions.checkServerTrusted(chain, authType, host)`，链校验+主机名校验一体；host 缺失直接拒绝。
- **R15 嗅探旧响应**：`parseCapture` 从**最新**（最后到达）的捕获响应往回找，SPA 切学期后不再导入旧学期。
- **R16 文件全量读取**：原生读取改后台线程 + 20MB 有界读取（超限早拒绝/实际字节截断判定），声明大小预检，MethodChannel 回调封回主线程。

### 请求与同步健壮性

- **R17 业务 400 清凭证**：refresh 与重放分离 try/catch；重放的业务错误原样上抛，不再误清新 token，错误语义保持 400。
- **R18 multipart 不可重放**：onRequest 阶段对 FormData 做内存快照（≤10MB），发送用重建的新实例；401 刷新后用快照重建重放。超限文件退化为不重放。
- **R10 离线滞留**：同步失败进入 1→2→4→8 分钟退避重试（封顶后维持），成功/登出清状态；登录态就绪后主动触发一次初始同步；`SyncRepository.sync()` single-flight 防叠加。
- **R09 调休不联动**：`overridesProvider`、`sectionTimeConfigProvider` 挂进 dataChangeEffects 联动器，调休/作息变化同样触发重排提醒→刷组件→静默同步。

### AI 日程

- **R24 单次/整组混淆（P0）**：reschedule/cancel 携带具体日期时走单次语义——原时段按学期周数展开成 custom 后摘掉该周（摘完为空则整条删），单次调课另建一条单周时段（新增 `ScheduleRepository.createSlot`）；确认卡片明示"仅X月X日这一节 / 整个学期该时段"。
- **R25 日程目标崩溃**：reschedule 按 target 类型分派，LocalEvent 走 `updateEvent` 更新日期/星期/时刻/占用节次，不再强制走课程时段分支。
- **R26 改时刻仍存原节次**：确认弹层记录 `_timeEdited`，改过时刻即清空节次表达，busySections/入库以时刻重新换算。

### 提醒 / 小组件

- **R19 定时接收器缺失**：manifest 注册 flutter_local_notifications 18 的三个接收器（ScheduledNotificationReceiver / ScheduledNotificationBootReceiver / ActionBroadcastReceiver）。
- **R20 重启恢复不可取消**：自研恢复链路整体退役——提醒调度/恢复/取消统一走插件链路；自研 BootReceiver 改为一次性清理旧版遗留闹钟（按缓存 id 重建 PendingIntent 后 cancel），NotificationReceiver 保留为 no-op 防漏网闹钟发错渠道。
- **R21 双周含单周**：`week >= 2 && week.isEven`。
- **R22 小组件无视调休**：`_coursesForDate` 先查当日 override，经 `effectiveWeekday` 投影（放假空、补课按指定星期），与 App 周视图同规则。
- **R23 跨午夜**：三重防线——Dart 60 秒定时器检测日期翻转即重刷组件+重排提醒；快照写入 `render_date`，原生 Provider 发现过期在标题追加"（打开 App 更新）"而非冒充今天；五个 widget xml `updatePeriodMillis` 0→1800000 兜底重渲染。

### 更新 / 广告

- **R30 强制更新（产品铁律）**：客户端整体移除强制更新阻断（弹窗、PopScope、forced 按钮态全部删除），服务端标志不再能阻断任何构建；两个旧断言测试随行为更新为"阻断代码必须绝迹"。
- **R31 旧更新缓存**：服务端判无更新时清除本地缓存；`cachedUpdate` 要求 `version_code > 当前`（过期缓存自动清除）；详情页仅在网络失败时才回退缓存。
- **R29 广告协议**：Dart 侧兼容 bool 与 `{'rewarded': bool}` 两种原生返回（解码抽成 `decodeRewardResult` 可单测），不再 TypeError。

### 结构

- **R32 冲突层分组**：展开层分组改用"当前组最大 endSection"连通分量，嵌套区间不再错拆。
- **R33 冲突层日期**：`_ConflictBlock` 接收列日期 `dayDate` 并传到弹层，冬夏作息随目标日期，不再隐式读今天。
- **R34 lint 入口**：新增根 `analysis_options.yaml`（flutter_lints + unawaited_futures/cancel_subscriptions 等，排除 .g.dart 与 plugins）。

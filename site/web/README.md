# 邗上课表 iPhone 网页版

这是部署到 `https://hanshang.seanyan.store/web/` 的静态 PWA 源码。它采用与 App 一致的“课表 / 导入 / 我的”三栏结构，支持账号登录/注册、周/日课表、课程增删改、学期设置、教务账号服务器导入、云同步、分享口令和 Web Push。

安全边界：网页只在内存保存 access token；不保存登录密码、refresh token、教务凭据或 API 响应。`sw.js` 只缓存本地静态壳，不缓存跨域 API 请求。

服务器代抓只建立单次短时 WebVPN/教务会话，不保存密码、Cookie、HAR 或截图；遇到验证码、短信或二次验证即停止。通知权限只能由用户从主屏幕图标打开后主动触发。

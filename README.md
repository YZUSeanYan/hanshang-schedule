# 邗上课表（hanshang-schedule）

面向扬州大学学生的课表管理 Android App：简洁清爽、无广告，支持教务课表导入、上课提醒、云端同步、桌面小组件与原生推送。

**当前版本：2.0.4+68** · **开源范围：Flutter Android 客户端** · **License：MIT**

## 功能

- 周视图 / 日视图 / 今日课程，单双周与自定义周次，春夏/秋冬两套作息自动切换
- 上课提醒（提前 5/10/15/30 分钟可选），重启后自动恢复
- 教务课表导入：App 内 WebView 引导、手动文本、课表截图与 Excel/CSV 表格
- 复杂表格与分小班课表：服务端优先使用规则解析，未识别时再使用 AI 辅助解析
- 多学校适配：通过 Ed25519 签名通道按学校下发引导、嗅探词和字段别名，无需更新 APK
- 云端同步：多端课表一致，支持增量拉取与删除墓碑
- 桌面小组件：今日课程 / 周课表 / 双日 / 单日，支持多尺寸与深色模式
- 分享码、共同空闲、节假日调课、深色模式与多色主题

## 快速开始

```bash
cd app
flutter pub get
# 修改 Drift 表结构后重新生成
dart run build_runner build --delete-conflicting-outputs
flutter test --no-pub

# 本地联调（HTTP 仅限 debug 构建）
flutter run --dart-define=API_BASE_URL=http://127.0.0.1:8000

# 正式构建必须注入 HTTPS 地址
flutter build apk --release --dart-define=API_BASE_URL=https://your-api-host/yzu
```

推送、远程配置公钥等构建参数通过 `--dart-define` 注入；缺省时相关功能关闭。Android 签名文件、密钥库、`.env` 和本地配置均不入库。详见 [App 构建说明](app/README.md)。

## 隐私与安全

- **不接收教务密码**：学校系统的账号密码只经过用户设备与学校服务器；App 不读取密码框，服务端没有接收教务密码的接口。
- **优先本地/规则解析**：只有本地规则无法识别时，才在用户主动操作后使用云端智能解析。
- **上传前脱敏**：姓名、学号、手机号等身份信息在设备端抹除，服务端再次脱敏；名单工作表不会送入大模型。
- **原文不留存**：智能解析所需的页面、截图或表格内容不写入业务数据库或日志；第三方模型仅用于当次解析。
- **配置防篡改**：远程教务适配配置使用 Ed25519 签名，校验失败时保留内置配置或最后一份有效配置。
- **账号安全**：登录密码仅以 bcrypt 不可逆哈希保存，刷新会话支持撤销。

## 项目结构与开源范围

```text
app/
├── android/          # Android 平台工程（签名配置不入库）
├── lib/
│   ├── core/         # 配置、数据库、通知、路由、主题、存储
│   ├── features/     # 课表、教务导入、同步、分享、更新、隐私等
│   └── import/       # WebView 嗅探与本地课表解析器
├── plugins/          # 本地维护的阿里云推送插件
└── test/             # 单元与组件测试
```

本仓库目前公开 Android 客户端；FastAPI 后端、PWA、手表端、运维脚本、真实课表样本和内部交接文档不在本仓库内。公开仓库不包含服务器私钥、签名密钥、访问令牌、用户数据或真实教务快照。

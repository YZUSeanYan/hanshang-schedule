# 邗上课表 · 手表助手（独立 App）蓝图

> 2026-10-17 · 把「连接手表、发送课表数据」从主 App 拆成独立 App。
> 主 App 不动（其「发送课表到手表」入口保持隐藏），手表端 `ble.js` 协议不变。

## 一、定位

单功能工具 App：**登录 → 取课表快照 → BLE 广播 → 手表「蓝牙导入」接收**。
包名 `cn.yzu.schedule.watchbridge`，纯 Kotlin + 系统控件（零第三方依赖，构建最稳），
本地侧载使用、不上架。

## 二、数据流（服务端契约已逐条核对 `server/app/api/v1/endpoints/{auth,share,sync}.py`）

1. `POST /yzu/api/auth/login`（用户名或邮箱 + 密码）→ access/refresh token（SharedPreferences）
2. `GET /yzu/api/sync/pull?since=0` → 学期列表（取 `is_current`，否则首个未删除）
3. `POST /yzu/api/share/create`（`{semester_uuid}`）→ 6 位分享码
4. `GET /yzu/api/share/{code}` → `data.payload` ＝ 服务端 `_snapshot_for_semester` 权威快照
   （与手表 `bleimport/applySnapshot` 结构完全同构：`semester{name,start_date,total_weeks}` +
   `courses[{name,teacher,color,slots[{day_of_week,start_section,end_section,weeks_type,custom_weeks,location}]}]`）
5. payload JSON → BLE 分片发送

选 share/create+preview 而不是客户端自组快照：快照由服务端权威生成，与手表导入路径零偏差。
副作用＝生成一个带 TTL 的分享码（主 App 现行做法相同，可被覆盖/过期，无害）。

## 三、BLE 协议（与手表 `ble.js` 约定，不变）

- 手机 = GATT Server + 可连接广播；Service `8F2A0001-…`、可读 Char `8F2A0002-…`
- 每帧 `[seq:1B][len:1B][data≤180B]`，seq 从 0 递增；结束帧 `0xFF 0x00`
- 手表 GATT Client 每 read 一次取一片（`onCharacteristicReadRequest` 按序回帧）
- 源码直接移植主 App `WatchBleTransfer.kt`，去掉 Flutter/EventChannel 耦合，改回调接口
- 120 秒无人连接自动停广播；发送完成 1.5 秒后自动停；发送中显示帧进度 n/m

## 四、UI（单 Activity 双面板，深色风与手表端一致）

**登录面板**：标题「邗上课表 · 手表助手」/ 说明「把课表发送到手表（蓝牙离线导入）」/
账号、密码输入 / 登录按钮 / 状态行。

**发送面板**：
- 顶部：学期名 + 「共 N 门课」
- 主按钮：**发送到手表**（全宽 56dp）
- 提示：先在手表打开「蓝牙导入课表 → 开始接收」，再点发送；保持手表与手机 10 米内
- 状态日志区（可滚动）：取快照… → 蓝牙广播中，等待手表… → 手表已连接 → 发送中 n/m → ✅ 完成 / 超时 / 错误原因
- 底部：退出登录

**权限**：Android 12+ `BLUETOOTH_SCAN/CONNECT/ADVERTISE`（SCAN 带 neverForLocation）；
≤11 `ACCESS_FINE_LOCATION`；`INTERNET`。点「发送」时按需申请（照抄主 App `MainActivity` 的分版本逻辑）。

## 五、安全约束（按生成期验收条件执行）

- 服务端请求只走 https；请求前校验 URL：scheme 必须 https，host 拒绝 localhost/环回/私网/保留地址
- 密码只进系统输入框与登录请求，不落日志；token 存应用私有 SharedPreferences

## 六、构建与验收

- 工具链与主 App 同版（缓存命中）：AGP 9.0.1 + Kotlin 2.3.20 + Gradle 9.1.0，JDK 17
- 签名：独立 keystore `watch-bridge/keystore.properties`（**不复用主 App 备案签名**）
- 验收：模拟器装 debug 包目检 UI（模拟器无 BLE，点发送提示蓝牙不可用属预期）；
  真机全链路（登录→快照→手表接收）与手表 BLE 联调一起做
